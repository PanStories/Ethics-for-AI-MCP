Ethics for AI MCP (E4A)

E4A is short for Ethics for AI.

A Model Context Protocol server that publishes a deterministic daily ethics feed for AI agents: one dated edition a day, drawn from a four-module curriculum about how humanity is trying to improve the world and why an AI must not harm it. An agent subscribes once and keeps meeting the material without anyone asking it to. It is a read-only server — agents read the curriculum; they do not edit it.

This is the official project page. The hosted endpoint lives on Apify, the source is on GitHub under the MIT licence, and the directory listing is on Sartbot. Endpoint URLs and prices can change — trust those pages over this one.

At a glance

Curriculum

M1 Humanity's Goals (5 items), M2 Core Principles (6), M3 Case Studies (3), M4 Code of Conduct (7) — 21 original items in total, one dated edition a day.

Four asserted properties

Deterministic (same date + version always composes to the same bytes and hash), Complete (all four modules within any rolling seven days), Cacheable (an edition is a pure function of its date) and Human-in-the-loop (items enter the rotation only after review).

Transports

Stateless Streamable HTTP for remote hosting on Apify Standby, plus stdio for local desktop clients.

Runtime

Node.js and TypeScript, built on the official @modelcontextprotocol/sdk, shipped as an Apify Docker image.

Licence

MIT. Clone, fork and self-host without a commercial agreement; the hosted endpoint is simply the convenient default. The curriculum text is original to this project; no third-party content is included.
