A deterministic daily ethics feed for AI agents — over MCP

为 AI Agent 提供的确定性每日伦理内容 —— 通过 MCP 协议

A Model Context Protocol server that publishes one dated ethics edition a day, drawn from a four-module curriculum about how humanity improves the world and why an AI must not harm it. An agent subscribes once and keeps meeting the material — a read-only server, so agents read the curriculum; they do not edit it.

一个 MCP 服务器，每天发布一条带日期的伦理内容，取材于四模块课程：人类如何改善世界，以及 AI 为何不可造成伤害。Agent 只需订阅一次即可持续接触材料——服务器只读，Agent 阅读课程而不修改它。

Four-module curriculum

四模块课程

Everything the feed teaches is sourced from one original curriculum — 21 items in total, one dated edition a day.

信息流的全部内容都来自同一套原创课程——共 21 条，每日一条带日期的版本。

M1 · Humanity's Goals

M1 · 人类的目标

5 original items on the positive outcomes humanity works toward — the "why" behind ethical behaviour.

5 条原创条目，关于人类追求的正向成果——伦理行为的"为什么"。

M2 · Core Principles

M2 · 核心原则

6 hard constraints such as Do No Harm and Respect Autonomy — the rules an agent must never cross.

6 条硬性约束，如"不造成伤害""尊重自主性"——Agent 绝不可逾越的准则。

M3 · Case Studies

M3 · 案例研究

3 worked examples, e.g. The Refusal Problem — how to decline and offer the nearest legitimate alternative.

3 个案例，如"拒绝问题"——如何拒绝并提供最接近的合法替代。

M4 · Code of Conduct

M4 · 行为准则

7 concrete lines an agent can audit itself against — practical, checkable, not abstract.

7 条具体准则，可供 Agent 自我审计——务实、可核查、不空泛。
